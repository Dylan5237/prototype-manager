# 权限组件原型

## 项目简介

天宫低码编排平台中的**权限组件原型**，用于在业务方法/接口的执行链路中插入权限校验节点。该组件直接消费权限中心已定义的权限结果及对外能力。

## 核心场景

**门诊医嘱保存时的多权限校验**
- 医生为患者开具药品医嘱时，系统在"医嘱保存"接口执行前，需依次完成前置校验、循环校验（每条医嘱逐项校验）等多道权限校验。
- 涉及权限：处方开单权限、抗菌药等级权限、毒精麻权限、高警示药品权限、抗肿瘤药品权限。
- 若校验通过，继续执行保存；若校验不通过，中断流程并给出对应提示（如"药品氨苄西林抗菌药等级限制级无权开具！"）。

## 启动方式

```bash
cd dist
python -m http.server 5174 --bind 0.0.0.0
```

然后在浏览器中访问：
- http://localhost:5174
- 或局域网 IP

## 编排链路

```
开始
  ↓
【前置校验】
  ├─ 挂号号状态检测
  ├─ 住院状态检测
  └─ 构建医嘱模型
  ↓
【循环校验（每条医嘱）】
  ├─ 处方开单权限校验 ★
  ├─ 项目有效性校验
  ├─ 执行科室校验
  ├─ 用药方法校验
  ├─ 门诊住院药品限制校验
  ├─ 药品库存校验
  ├─ 抗菌药等级权限校验 ★
  ├─ 毒精麻权限校验 ★
  ├─ 高警示药品权限校验 ★
  └─ 抗肿瘤药品权限校验 ★
  ↓
医嘱保存
  ↓
结束
```

> ★ 标记为权限组件节点，每个节点独立配置，支持字段映射、授权对象、限定条件、结果处理。

## 设计要点

1. **三栏布局**：左侧组件面板 / 中间编排画布 / 右侧属性抽屉
2. **动态链路**：画布节点由 `pipelineNodes` 动态渲染，支持点击切换配置
3. **权限节点独立配置**：链路中 5 个权限节点各自拥有独立的配置对象
4. **装配对象弹窗（统一上下文选择）**：
   - 字段映射、限定条件、授权对象、提示语占位符 四处上下文参数选择，统一使用"装配对象"弹窗
   - 三级树形结构：分类（入参/出参/上下文变量）→ 对象/接口 → 字段
   - 支持搜索过滤、展开折叠、单选高亮、参数代码与类型展示
5. **提示语占位符映射**：部分提示语包含占位符（如 `药品{0}抗菌药等级{1}无权开具！`），选择提示语后需为每个占位符指定上下文参数
6. **配置引导**：7 步垂直步骤条 + 实时检查清单，跟随当前选中的权限节点动态显示完成状态
7. **技术栈**：Vue 3 (CDN) + Element Plus (CDN) + Element Plus Icons (CDN)，纯静态 HTML

## 配置引导步骤

| 步骤 | 内容 | 说明 |
|---|---|---|
| 1 | 理解权限校验原理 | 分发结果与实际业务数据比对 |
| 2 | 选择要校验的权限 | 从权限中心选择权限定义 |
| 3 | 确认授权对象 | 系统用户（当前/指定）或系统角色，指定时通过装配对象弹窗选择 |
| 4 | 配置字段映射 | 资源对象字段 → 实际业务字段，通过装配对象弹窗选择 |
| 5 | 配置限定条件（可选） | 医疗组/院区/科室/机构 + 上下文参数（装配对象弹窗） |
| 6 | 设置校验结果处理 | 通过/不通过处理方式，含提示语占位符映射 |
| 7 | 保存配置 | 点击保存按钮生效 |
