# 阶段 22.1 项目模块高保真原型

这是用于需求对齐的独立静态原型，不连接 FuxiPlatform 真实 API，也不会写入项目、原型、成员或快照数据。

## 查看方式

直接打开同目录的 `index.html`。推荐桌面宽度 `1440 × 900` 查看；页面包含基础响应式降级。

## 可点击路径

1. 在“项目”页切换「全部项目 / 我负责 / 有待处理」，搜索项目并进入“客户服务平台”。
2. 在项目工作台点击左侧「客户列表 / 服务工单 / 数据报表 / 用户权限 / 通知配置」查看不同工作区状态。
3. 点击「待处理」中的“查看效果”打开候选审核弹窗；点击「最近活动」查看时间线。
4. 点击「成员」「快照」「全屏预览」查看上下文弹窗。
5. 点击「用户权限」→「选择原型绑定」体验未绑定状态到已绑定状态的转换。

## 本稿需要确认的决策

- 项目列表摘要是否保留“绑定原型 / 待确认候选 / 最近活动”三项。
- 工作台右侧是否默认显示“待处理”，成员和快照是否继续放在弹窗/抽屉。
- 打开项目时是否恢复上次菜单位置，还是固定打开第一个已绑定菜单。
- “有待处理”是否只统计 `ready` 候选，还是包含领取中、预览失败和已过期任务。
