# DEMO-XXX｜案例演示脚本

关联案例：`CASE-XXX`

## 演示目标

用尽量短的时间证明：这是一个真实业务任务；伏羲确实完成了关键工作；结果可验收；相比传统方式有明确提效且质量不下降。

## 30～60 秒核心录屏脚本

### 1. 业务问题（5～10 秒）

一句话说明原任务和原工作方式。

### 2. 在伏羲发起（5～10 秒）

展示真实入口和任务目标。避免在录屏中暴露敏感业务数据、token、连接码或个人隐私。

### 3. AI 完成（10～20 秒）

只展示对业务结果有价值的关键过程，不需要展开底层 MCP/工具调用。

### 4. 回到伏羲验收（10～20 秒）

必须看到真实结果，例如：

- 原型/版本存在；
- 预览正常；
- 关键页面和交互可操作；
- 项目场景下待审修订、退回/采用流程正确。

### 5. 前后对比（5～10 秒）

- 传统方式：`[X] 分钟`
- 伏羲方式：`[Y] 分钟`
- 节时率：`[Z%]`
- 质量：无下降 / 说明差异
