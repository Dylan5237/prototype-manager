# 最终申报材料检查清单

## A. 资格与报名

- [ ] 工具仍属于公司内部业务需求工具，不属于对外商业化产品/产品组成部分
- [ ] 工具负责人、申报部门/业务群、正式入口已确认
- [ ] 目标用户定义和人数已冻结
- [ ] 申报奖项最终决定已记录
- [ ] 报名材料在 2026-09-15 前提交

## B. 统计窗口

- [ ] 所有正式数据严格来自 2026-09-16 ～ 2026-11-15
- [ ] 内部测试、重复刷新、无效调用、批量造数已剔除
- [ ] 有效任务口径有书面定义
- [ ] 用户去重、部门归属、任务去重方式可复核
- [ ] 使用频率目标值/达成率口径在统计期开始前冻结

## C. 使用广度与频率

- [ ] 目标用户清单完整
- [ ] 去重有效用户数可从日志/台账回查
- [ ] 覆盖率计算明细完整
- [ ] 有效任务总数可回查
- [ ] 重复使用人数可回查
- [ ] 如报综合示范奖，至少两个独立部门/业务单元的证明完整

## D. 准确可靠

- [ ] 不少于 10 个代表性案例
- [ ] 统一验收规则已冻结
- [ ] 每个案例有复核记录
- [ ] 正确率计算明细完整
- [ ] 严重错误定义明确
- [ ] 严重错误数及处理记录完整
- [ ] 不以 AI 自报成功代替业务复核

## E. 效率与效果

- [ ] 不少于 10 组同类任务前后对比（建议 20 组）
- [ ] 传统方式基准来源可信且可解释
- [ ] 伏羲耗时包含人工准备、复核和返工
- [ ] 节时率公式统一
- [ ] 极端/异常高节时率已人工复核
- [ ] 返工率与质量变化有记录
- [ ] 最终结论没有选择性只展示最好样本

## F. 流程规范化

- [ ] 统一正式入口证据
- [ ] 操作手册/Help Center 证据
- [ ] 责任人/维护机制
- [ ] 创建、修改、项目审核、分享的流程证据
- [ ] 日志/任务/版本记录
- [ ] 用户反馈闭环
- [ ] release / 更新记录
- [ ] 持续优化证据

## G. 案例与录屏

- [ ] 10 个正式代表案例已选定
- [ ] 10 个案例均有录屏
- [ ] 每个录屏可清楚看到真实任务、结果、前后对比
- [ ] 所有录屏已脱敏，无密码/token/个人隐私
- [ ] 10 个案例均准备现场随机演示路径
- [ ] 任抽 1～2 个案例可以在 5～8 分钟总体演示限制内完成
- [ ] 异常处理至少有一个可解释案例

## H. 最终数字交叉校验

- [ ] 报名表数字 = 数据汇总数字
- [ ] 汇总数字 = registry/weekly/cases/evidence 可追溯数字
- [ ] 使用广度、频率、准确率、节时率计算公式复核通过
- [ ] 目标用户人数没有事后扩大或缩小以优化评分
- [ ] 跨部门数量与证明一致
- [ ] 每个关键结论至少有一项底层证据

## I. 数据安全

- [ ] GitHub 公共仓库无密码、token、连接码
- [ ] 无未经授权的个人手机号、邮箱等个人信息
- [ ] 无未脱敏的敏感业务数据
- [ ] 私有证据只在仓库记录编号、校验值和内部稳定位置

## J. 提交时间

- [ ] 报名材料：2026-09-15 前
- [ ] 数据统计截止：2026-11-15
- [ ] 数据材料：2026-11-20 前
- [ ] 现场评审准备：2026-12-04 前
