### 内部目标

不将目标当成实测结果。用于运营方向的目标为：

- 使用广度：力争达到 60%～79% 以上目标用户覆盖；
- 使用频率：力争目标使用达成率 ≥60%；
- 准确可靠：争取 ≥95% 且无严重错误，但必须由真实样本决定；
- 流程规范化：把现有流程证据化，重点证明闭环运行和持续优化；
- 效率与效果：50%～79% 节时已具有较强竞争力；达到 ≥80% 时必须额外复核口径和质量是否下降。

### 综合示范奖 Gate

只有同时满足下列条件才进入最终双奖申报：

- [ ] 至少两个相互独立部门/业务单元有真实使用；
- [ ] 每个部门有联系人、目标用户、去重有效用户和有效任务；
- [ ] 至少有一个可复核代表案例；
- [ ] 使用不是培训、演示或临时测试；
- [ ] 能证明具备复制推广条件。

建议在 2026-10-15 做第一次 Gate 判断；不满足时不为了双奖强行扩大使用范围。

## 三、评分换算

官方统一公式：

`单项加权得分 = 0～5 分评价值 / 5 × 单项权重`

主要 0～5 分区间：

- 使用广度：无有效用户 / <20% / 20%～39% / 40%～59% / 60%～79% / ≥80%
- 使用频率：无有效记录 / <20% / 20%～39% / 40%～59% / 60%～79% / ≥80%
- 准确可靠：未测试 / <70% / 70%～79% / 80%～89% / 90%～94% / ≥95% 且无严重错误
- 效率与效果：未验证 / <20% / 20%～29% / 30%～49% / 50%～79% / ≥80% 且质量不下降

流程规范化需结合通知关于统一入口、说明、纳入流程、系统嵌入/方案、闭环持续优化的具体规则人工判定。

## 四、更新规则

- 周度事实写入 `registry/weekly-metrics.csv`；
- 每周详细解释写入 `weekly/`；
- 本 Scorecard 只维护最新事实快照；
- 所有评分必须能回到原始证据；
- 不允许为了达到档位而改变目标用户分母或剔除不利的真实样本。
