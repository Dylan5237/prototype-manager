## 状态说明

- `in-progress`：已进入当前迭代，但尚未满足完成条件。
- `local-verified`：实现和本地回归已通过，但命名环境验收尚未完成，仍不视为交付完成。
- `deferred`：已确认暂放，不进入当前迭代。
- `pending`：尚未完成，等待真实验收、外部条件或明确决策。
- `decision-needed`：已有现场或产物，但是否清理、是否继续需要人工决定。
- `out-of-scope`：当前默认产品合同不包含，只有重新纳入范围才启动。
- `cancelled`：方向已明确废弃，不再作为待交付能力。

## BL-007 需求边界与验收口径

- **目标**：平台管理员可以发现并打开任意用户创建、未分享或已绑定项目的有效原型，完成只读详情和当前版本预览。
- **默认范围**：包含有效原型的列表、详情、README/文件元数据和当前可预览版本；不默认包含回收站对象、物理删除对象或历史版本预览。
- **权限边界**：本需求不新增编辑、上传新版本、删除、恢复、分享、成员管理、协作采用和其他项目变更权限；管理员既有管理权限保持不变，这些能力仍按各自授权控制。
- **安全要求**：管理员角色在列表、详情和 HTML 预览相关后端路由使用同一套可审计判定；本需求不新增下载权限。非管理员仍只能访问其所有、被分享或明确授权的原型，不能因新增管理员能力扩大访问范围。
- **可观测性**：管理员预览只读记录打开/预览事件，不记录或暴露访问令牌，不改变原型内容和版本。
- **跨仓依据**：需要修改 FuxiPlatform 的权限服务、API、前端入口和测试；不修改 `prototype-manager-skills`，因为本需求不改变 Skill 入口、生成规范、runtime/profile、ZIP、安装或 MCP 工具契约。Skill 侧仅做兼容性回归。

## 记录规则

1. 新事项先写入本文件，再进入实现计划。
2. `in-progress` 必须有当前迭代入口和可复核验收条件；`deferred` 不自动实现。
3. `pending` 必须写明阻塞来源，不能用本地测试或历史结果替代真实验收。
4. `decision-needed` 在人工确认前不执行删除、回滚或其他破坏性操作。
