## 目标

平台管理员可以发现并打开任意用户创建、未分享或已绑定项目的有效原型，查看详情、README/文件元数据和当前版本预览；非管理员访问边界保持为所有者、明确分享或其他既有授权。

## 本次实现

- 统一 JWT `roles`/兼容 `role` 的角色解析和管理员判定，兼容历史单值 token。
- 管理员 `scope=all` 列表可返回所有未删除原型；详情、README、文件、版本、评论和当前/历史 HTML 预览使用同一有效原型访问边界。
- 非管理员移除“任意登录 viewer/uploader 均可访问”的回退路径，仅允许所有者或明确分享用户；回收站原型不进入只读预览范围。
- 预览访问仅记录既有打开/预览事件，不写入访问令牌，不改写原型内容、版本或项目绑定。
- 配套仓库 `D:\_projects\skills\prototype-manager-skills` 未修改：本需求不改变 Skill 入口、生成规范、runtime/profile、ZIP、安装或 MCP 工具契约。
